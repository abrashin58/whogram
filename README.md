# Whogram 2.0

iOS-клиент Telegram на SwiftUI + [TDLib](https://github.com/tdlib/td) через [TDLibKit](https://github.com/Swiftgram/TDLibKit).
Автор: whomakson.

## Оформление и возможности

- **Design Lab:** отдельная вкладка с живым предпросмотром. Восемь встроенных тем, настраиваемая Custom и библиотека именованных пресетов. Без сохранённого выбора стартует светлая Telegram Classic: белый фон, синий акцент и голубые исходящие сообщения. Старые темы и настройки не перезаписываются.
- **Нативные поверхности:** Liquid Glass на iOS 26, материал на iOS 16–25 и непрозрачные панели при включённом системном параметре «Понижение прозрачности». Переходы учитывают системное уменьшение движения.
- **Сохранение:** встроенные темы неизменяемы. Чтобы настроить одну из них, скопируйте её в Custom. Собственные снимки темы можно сохранять, переименовывать, применять и удалять. Фотография обоев хранится на устройстве отдельно, не копируется в снимок и не отправляется в Telegram.
- **Иконка:** монохромная монограмма WG; редактируемый вектор находится в `Support/Brand/Whogram-AppIcon.svg`. Xcode собирает основной значок из `AppIcon.appiconset`.

- Стикеры: недавние, поиск по слову или эмодзи, просмотр и отправка из набора по нажатию на стикер в чате. WebP показывается как изображение, TGS/WebM используют доступную миниатюру; проигрывание этих форматов не заявляется.
- Медиа: фото с масштабированием, видеоплеер, GIF, отдельный аудиоплеер с перемоткой, документы через Quick Look, прогресс и повтор загрузки.
- Голосовые: запись с разрешением микрофона, таймером, отменой и фактической звуковой волной; отправка через TDLib. Для записи используется M4A, предусмотренный схемой `inputVoiceNote`. Воспроизведение зависит от поддержки формата на устройстве.
- Пересылка, реакции, ответы, редактирование, поиск в чате
- Фильтры чатов: «Все / Непрочитанные / Личные / Группы / Каналы»; закреплённые выше остальных
- Настройки: профиль, информация о чате, типы сообщений

## Что было сломано и что исправлено

| Проблема | Исправление |
| --- | --- |
| Сборка в Actions падала (exit code 65) | `TDLibManager` использовал `ObservableObject`/`@Published` без `import Combine` — файл не компилировался. Добавлен импорт |
| В `project.yml` не было `Info.plist` | Теперь он генерируется XcodeGen (`Support/Info.plist`) |
| `xcodebuild -scheme Whogram` мог не найти схему | Схема `Whogram` явно объявлена в `project.yml` |
| Сообщения в чате показывались вверх ногами (трюк с `scaleEffect(y: -1)`) | Нормальный `ScrollView` + `ScrollViewReader` с автопрокруткой вниз |
| Чаты шли в случайном порядке | Сортировка по дате последнего сообщения |
| Вкладки «Личное / Работа / Каналы» ничего не фильтровали | Реальные папки: Все / Личные / Группы / Каналы |
| `loadChats` отвечает `404 Not Found`, и это показывалось как ошибка | Ответ 404 игнорируется |
| Не было выхода из аккаунта | Кнопка «Выйти из аккаунта» в настройках (`logOut`) |
| Нет понятного лога при падении CI | Билд-лог и `.xcresult` выгружаются артефактом `build-logs` |

## Требования для сборки

- macOS с Xcode 26+ (минимальная версия приложения: iOS 16)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
- Интернет для зафиксированной ревизии TDLibKit и бинарного TDLibFramework

## Локальная сборка (macOS)

```bash
xcodegen generate
open Whogram.xcodeproj
```

Дальше — обычный запуск на симуляторе/устройстве из Xcode.
Для устройства нужен свой Apple ID в *Signing & Capabilities*.

## Проверки

**Собрать iOS-приложение в Codespaces нельзя**: Codespaces — это Linux-контейнер,
там нет Xcode и iOS SDK. Поэтому `xcodebuild` там не запустится никогда.

В Linux или macOS с установленным Swift можно проверить синтаксис и запустить тесты чистого Swift:

```bash
bash scripts/check-syntax.sh
bash scripts/check-core.sh
```

Тесты проверяют стартовую тему и сохранение пресетов, HEX и контраст, повторное открытие каталога TDLib, отказ создавать пустую замену пропавшей базе, миграцию записи одного профиля без смены UUID, раздельные ключи, локальный выход в модели, разрешения запросов TDLib, продвижение курсора истории и 5-битную кодировку звуковой волны.
Они не заменяют сборку iOS и проверку на устройстве.

Для ручной проверки на iPhone: войдите в Telegram; откройте Design Lab, переключите темы и перезапустите приложение; отправьте текст, фото и файл; запишите, отмените и отправьте голосовое; проверьте поиск стикеров и набор, видео, GIF, аудио и документы. Проверьте также тёмный/светлый режимы, крупный системный шрифт, уменьшение движения и работу без разрешения микрофона.

Проверка сессии после инцидента: не используйте основной аккаунт. На двух отдельных тестовых аккаунтах сначала оставьте активный вход в официальном Telegram. Запустите Whogram и убедитесь, что без подтверждения он не подключается. Введите свои данные приложения в Whogram, подтвердите подключение и проверьте, что официальный клиент остался авторизован. В настройках выберите «Сменить или добавить аккаунт» и добавьте второй аккаунт. Переключитесь между аккаунтами в обе стороны: ожидается восстановление без нового кода и без пересечения чатов. Повторите после принудительного закрытия, перезагрузки устройства, обновления и временного отключения сети. Выполните подтверждённый выход из одного профиля и убедитесь, что второй профиль и официальный клиент не затронуты. Если официальный клиент потеряет сеанс, прекратите проверку; не повторяйте вход. Сообщить можно время инцидента и диагностическую метку из Whogram, если она появилась. Не отправляйте номер, коды, пароли или файлы базы.

В длинном чате проверьте, что сначала показываются последние сообщения, а при прокрутке вверх догружается предыдущая страница. Убедитесь, что входящее сообщение не уводит экран вниз во время чтения старых. Проверьте ошибку и повтор истории без сети, а также открытие фото из уже показанной миниатюры.

## Сборка через GitHub Actions

1. Сделайте push в `main` или соответствующую рабочую ветку. Для push в `whogram-session-recovery` и PR в `main` выполняются Debug и Release. Запустить сборку можно также вручную в Actions → Build iOS App.
2. Дождитесь зелёного билда.
3. Скачайте артефакт **Whogram-IPA-Debug** или **Whogram-IPA-Release** (внизу страницы запуска).
4. Если сборка не прошла, скачайте соответствующий артефакт **build-logs-…** и смотрите `build.log`.

`.ipa` неподписанный: установить на iPhone можно через AltStore / Sideloadly
со своим Apple ID (срок жизни подписи — 7 дней на бесплатном аккаунте).

## Важно про безопасность

В сборку, `Info.plist` и CI данные Telegram API не встраиваются. Введите свою пару непосредственно в Whogram на iPhone; тот же код используется в Debug и Release, TDLib получает значения из записи выбранного профиля в локальном Keychain. Для ранее опубликованного ID Whogram показывает отдельное предупреждение и требует явного подтверждения. Это не проверка и не гарантия того, что Telegram принимает пару. Для новых установок рекомендуется собственная пара, полученная по [инструкции Telegram](https://core.telegram.org/api/obtaining_api_id).

После холодного запуска нужно выбрать аккаунт и подтвердить подключение. Действующему сохранённому сеансу код не нужен. В настройках команда «Сменить или добавить аккаунт» закрывает клиент через `close`, ждёт `authorizationStateClosed` и возвращает к выбору аккаунта. Временный разрыв сети обрабатывает сам TDLib. `logOut` отправляется только после отдельного подтверждения для текущего профиля; список остальных профилей от него не меняется.

Каталоги из `main` в `Documents/Whogram` остаются нетронутыми: эта сборка их не открывает, не переносит и не удаляет, поскольку инцидент мог быть связан с прежним сеансом или конфигурацией. Для профиля из `whogram-stability-icon` сохраняются прежние UUID, путь `Application Support/WhogramSessions/<UUID>` и параметры открытия базы; запись Keychain `identity-v1` остаётся на месте. Новые профили имеют собственные UUID, базы, каталоги файлов и ключи шифрования. Каталог исключён из резервного копирования; базы и ключи авторизации не следует переносить между устройствами.

В `main` клиент автоматически открывал старую базу с публичной общей парой. Команд завершения других сеансов на проверенном пути запуска не найдено. Это не устанавливает точную причину инцидента: в [обсуждении похожего случая](https://github.com/tdlib/td/issues/3101) разработчик TDLib указывает на серверные механизмы безопасности Telegram. Whogram не может предотвратить их срабатывание или восстановить уже отозванную сервером сессию.
