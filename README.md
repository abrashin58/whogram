# Whogram 2.0

iOS-клиент Telegram на SwiftUI + [TDLib](https://github.com/tdlib/td) через [TDLibKit](https://github.com/Swiftgram/TDLibKit).
Автор: whomakson.

## Оформление и возможности

- **Design Lab:** отдельная вкладка с живым предпросмотром. Семь встроенных тем, настраиваемая Custom и библиотека именованных пресетов. Можно менять акцент (в том числе через HEX), поверхности, фон, входящие и исходящие пузырьки, плотность списка, аватары, панель ввода, обои, шрифт и скорость анимаций.
- **Нативные поверхности:** Liquid Glass на iOS 26, материал на iOS 16–25 и непрозрачные панели при включённом системном параметре «Понижение прозрачности». Переходы учитывают системное уменьшение движения.
- **Сохранение:** встроенные темы неизменяемы. Чтобы настроить одну из них, скопируйте её в Custom. Собственные снимки темы можно сохранять, переименовывать, применять и удалять. Фотография обоев хранится на устройстве отдельно, не копируется в снимок и не отправляется в Telegram.
- **Иконка:** монохромная монограмма WG; редактируемый вектор находится в `Support/Brand/Whogram-AppIcon.svg`. Xcode собирает основной значок из `AppIcon.appiconset`.

- Стикеры: недавние, поиск по слову или эмодзи, просмотр и отправка из набора по нажатию на стикер в чате. WebP показывается как изображение, TGS/WebM используют доступную миниатюру; проигрывание этих форматов не заявляется.
- Медиа: фото с масштабированием, видеоплеер, GIF, отдельный аудиоплеер с перемоткой, документы через Quick Look, прогресс и повтор загрузки.
- Голосовые: запись с разрешением микрофона, таймером, отменой и фактической звуковой волной; отправка через TDLib. Для записи используется M4A, предусмотренный схемой `inputVoiceNote`. Воспроизведение зависит от поддержки формата на устройстве.
- Пересылка, реакции, ответы, редактирование, поиск в чате
- Папки в чатах: «Все / Личные / Группы / Каналы», сортировка по важности
- Настройки: профиль, информация о чате, типы сообщений

## Что было сломано и что исправлено

| Проблема | Исправление |
| --- | --- |
| Сборка в Actions падала (exit code 65) | `TDLibManager` использовал `ObservableObject`/`@Published` без `import Combine` — файл не компилировался. Добавлен импорт |
| В `project.yml` не было `Info.plist` | Теперь он генерируется XcodeGen (`Support/Info.plist`) |
| `xcodebuild -scheme Whogram` мог не найти схему | Схема `Whogram` явно объявлена в `project.yml` |
| Сообщения в чате показывались вверх ногами (трюк с `scaleEffect(y: -1)`) | Нормальный `ScrollView` + `ScrollViewReader` с автопрокруткой вниз |
| Чаты шли в случайном порядке | Сортировка по дате последнего сообщения |
| Вкладки «Личное / Работа / Каналы» ничего не фильтровали | Реальные папки: Все / Личные / Группы / Каналы |
| `loadChats` отвечает `404 Not Found`, и это показывалось как ошибка | Ответ 404 игнорируется |
| Не было выхода из аккаунта | Кнопка «Выйти из аккаунта» в настройках (`logOut`) |
| Нет понятного лога при падении CI | Билд-лог и `.xcresult` выгружаются артефактом `build-logs` |

## Требования для сборки

- macOS с Xcode 26+ (минимальная версия приложения: iOS 16)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
- Интернет для зафиксированной ревизии TDLibKit и бинарного TDLibFramework

## Локальная сборка (macOS)

```bash
xcodegen generate
open Whogram.xcodeproj
```

Дальше — обычный запуск на симуляторе/устройстве из Xcode.
Для устройства нужен свой Apple ID в *Signing & Capabilities*.

## Проверки

**Собрать iOS-приложение в Codespaces нельзя**: Codespaces — это Linux-контейнер,
там нет Xcode и iOS SDK. Поэтому `xcodebuild` там не запустится никогда.

В Linux или macOS с установленным Swift можно проверить синтаксис и запустить тесты чистого Swift:

```bash
bash scripts/check-syntax.sh
bash scripts/check-core.sh
```

Тесты проверяют применение и сохранение пресетов, сохранение Custom при переключении тем, HEX и контраст, повторное открытие существующего каталога TDLib, продвижение курсора истории и 5-битную кодировку звуковой волны.
Они не заменяют сборку iOS и проверку на устройстве.

Для ручной проверки на iPhone: войдите в Telegram; откройте Design Lab, переключите темы и перезапустите приложение; отправьте текст, фото и файл; запишите, отмените и отправьте голосовое; проверьте поиск стикеров и набор, видео, GIF, аудио и документы. Проверьте также тёмный/светлый режимы, крупный системный шрифт, уменьшение движения и работу без разрешения микрофона.

Проверка сессии после инцидента: не используйте основной аккаунт. На отдельном тестовом аккаунте сначала оставьте активный вход в официальном Telegram. Запустите Whogram и убедитесь, что без подтверждения он не подключается. Введите свои данные приложения, подтвердите подключение и проверьте, что официальный клиент остался авторизован. Проверьте перезапуск Whogram и явное подключение без повторного ввода кода, возврат сети и подтверждённый выход только из Whogram. Если официальный клиент потеряет сеанс, прекратите проверку; не повторяйте вход. Сообщить можно время инцидента и диагностическую метку из Whogram, если она появилась. Не отправляйте номер, коды, пароли или файлы базы.

В длинном чате проверьте, что сначала показываются последние сообщения, а при прокрутке вверх догружается предыдущая страница. Убедитесь, что входящее сообщение не уводит экран вниз во время чтения старых. Проверьте ошибку и повтор истории без сети, а также открытие фото из уже показанной миниатюры.

## Сборка через GitHub Actions

1. Сделайте push в `main`, `whogram-2-redesign` или `whogram-stability-icon`. Сборку также можно запустить вручную в Actions → Build iOS App, выбрав Debug или Release; для push используется Debug.
2. Дождитесь зелёного билда.
3. Скачайте артефакт **Whogram-IPA** (внизу страницы запуска).
4. Если билд упал — скачайте артефакт **build-logs** и смотрите `build.log`.

`.ipa` неподписанный: установить на iPhone можно через AltStore / Sideloadly
со своим Apple ID (срок жизни подписи — 7 дней на бесплатном аккаунте).

## Важно про безопасность

В сборке нет общего `api_id`/`api_hash`. По [инструкции Telegram](https://core.telegram.org/api/obtaining_api_id) получите собственную пару на [my.telegram.org](https://my.telegram.org/) и введите её непосредственно на iPhone. Данные сохраняются в локальной связке ключей устройства. Подтверждение подключения требуется после холодного запуска приложения или закрытия клиента TDLib; оно не означает повторный вход, если новый кешированный сеанс всё ещё действителен. Временный разрыв сети обрабатывает сам TDLib.

Каталоги старой установки в `Documents/Whogram` не удаляются и не открываются новой сборкой. Новая база создаётся в `Application Support/WhogramSessions` в отдельном каталоге, привязанном к записи связки ключей, и исключается из резервного копирования. Не копируйте базы или ключи авторизации между устройствами. Блокировка команд завершения чужих сеансов в Whogram не может отменить решения Telegram на сервере ([обсуждение в TDLib](https://github.com/tdlib/td/issues/3101)).
